# Google Flow: 4 clips v2 (C001 ka test dekh kar prompt theek kiya)

## C001 ka nateeja (jo aap ne bheja)
**Theek aaya:** seedha camera mein dekhta hai, baal wahi, koi host ya dusri awaaz nahi, koi zoom nahi, close-up. Bahut behtar.
**Do masle:**
1. **Neeche likha aa gaya "No michopope"** (pehle 2 second). Wajah: mere prompt mein "No microphone" likha tha aur Flow ne use subtitle bana diya. Is version mein wo lafz hata diye.
2. **Lambe waqfe:** "She said you're too old" ke baad 1.4 second ki khamoshi, phir "Listen carefully", phir 1.4 second ki khamoshi. Isi se "ruk ruk ke" lagta tha. Is version mein likha hai: "har jumla pichle ke foran baad, gap 0.25 second se zyada nahi."

Edit mein maine dono ko theek kar diya (text dhak diya, waqfe chhote kiye), lekin agli clips mein ye galti na ho, is liye prompt badla hai.

## Ab kya banayein
**C002, C003, C004** (naye prompt se). C001 dobara banane ki zaroorat nahi, wo edit mein theek ho gayi hai.
Har clip mein start frame wahi: `dorian-closeup-start-frame.png`.

## Script (4 clips ke liye 2 jumle hatai gayi hain)
Hata diye: "Stop joking about it first." aur "Say it once, calmly, and move on." Kyunke Flow 8 second mein ~15 lafz se zyada aaram se nahi bolta.
